# Touché — Piano practice

A single-page piano trainer: a daily practice plan, public-domain songs with falling notes and fingering (Listen / Wait / Play & score), technique (scales, arpeggios, five-finger patterns, Hanon, chords, cadences, accompaniment patterns), rhythm drills (read & tap, inner pulse, two-hand independence, metronome), note reading, ear training and self-recording.

Open `index.html` in Chrome or Edge, or visit the GitHub Pages site. Works with a digital piano over USB/Bluetooth MIDI, an acoustic piano via the microphone, the on-screen keyboard, or the computer keyboard. Progress is saved in the browser.
